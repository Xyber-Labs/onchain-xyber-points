# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-02-13

### Added
- Solana program (Token-2022) for minting non-transferable XP tokens with nonce-based replay protection
- TypeScript SDK with three-level instruction pattern (Ix / Tx / send)
- CLI (`xyber-points`) with `initialize` and `mint-points` commands
- PDA helpers for config, points mint, and nonce accounts
